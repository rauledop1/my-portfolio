## 📈 Características Técnicas del Dashboard

### **Pipeline de Datos**
```python
# Flujo automatizado
NASA FIRMS → Python → DuckDB → Power BI → Dashboard Live
```

### **Procesamiento Geoespacial**
- **Datos de entrada**: CSV con coordenadas lat/lon
- **Transformación**: Conversión a geometrías espaciales
- **Análisis**: Intersección con límites administrativos
- **Salida**: Dataset enriquecido para visualización

### **Funcionalidades**
- ✅ Actualización automática cada 48h
- ✅ Filtros por satélite (MODIS, VIIRS)
- ✅ Filtros por horario (día/noche)
- ✅ Zoom por región administrativa
- ✅ Exportación de datos
