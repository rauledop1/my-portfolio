Descripción Técnica del Proyecto

Este proyecto se enfoca en automatizar un dashboard espacial en Power BI PRO, integrando datos de incendios en tiempo real del sistema FIRMS (Fire Information for Resource Management System) de la NASA. Utilizo Python y DuckDB para el procesamiento y transformación de datos, así como para la gestión de datos espaciales de ocurrencias de incendios y límites administrativos.

El pipeline de datos involucra la obtención de archivos CSV con detecciones de incendios, como MODIS_C6_1_South_America_48h.csv y MODIS_C6_1_Central_America_48h.csv. Los datos incluyen observaciones satelitales y timestamps de adquisición, mientras que las coordenadas espaciales se transforman en puntos geométricos usando funciones espaciales de DuckDB como ST_Point() y ST_Intersects().
